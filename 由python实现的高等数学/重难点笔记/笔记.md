# 第一章 函数

## 1. 周期性
若存在 $f(x+T)=f(x)$，则满足条件的**最小正数 $T$** 为函数的最小正周期。
若内层周期 T，外层周期 \(T'\)
整体周期：T 和 \(T'/k\) 的最小公倍数
例：\(y=\sin(2x)\)：内层周期 \(\pi\) → 整体 \(\pi\)
❌ 易错：直接用外层周期 \(2\pi\)

## 2. 嵌入式信号常用特性
| 特性         | 作用                                                         |
| :----------- | :----------------------------------------------------------- |
| 周期性       | 时钟、PWM 波、正弦交流电的生成与处理                         |
| 奇偶对称     | 波形分解、滤波运算、谐波分析                                 |
| 单调特性     | 传感器线性输出、稳压输出、缓升缓降控制                       |
| 有界性       | ADC 采样限幅、电气限幅、防止程序数值溢出                     |
| 连续性       | 区分模拟连续信号与数字离散信号                               |
| 缓变 / 陡变  | 对应微分大小，用于边沿检测、突变故障判断                     |

## 4.奇偶性判断
口诀：内奇则奇，内偶则偶，内非奇非偶则整体非奇非偶

例：y=\sin(x^2)：内层偶 → 整体偶
例：y=\cos(x^3)：内层奇 → 整体奇
❌ 易错：直接看外层奇偶，忽略内层
