# 电路模型与电路定律 理论笔记

## 一、电路和电路模型
### 1. 电路的定义
电路是由电气设备和元器件按一定方式连接起来，为电流流通提供的闭合路径，主要功能包括：
- 能量的传输、分配与转换
- 信号的产生、处理与传输

### 2. 电路模型
- 定义：由**理想电路元件**构成的电路，用于对实际电路进行理论分析和计算。
- 理想元件：只保留单一物理特性，忽略次要效应的简化模型（如理想电阻、电容、电感）。

### 3. 集总参数电路与分布参数电路
- **集总参数电路**：实际电路的尺寸远小于电路工作频率下电磁波的波长，可采用集总参数分析（如低频电子电路）。
- **分布参数电路**：不满足集总条件的电路，如高频、微波电路，需用分布参数理论分析。

## 二、电压和电流的参考方向
### 1. 参考方向的定义
参考方向是人为规定的电压、电流的计算方向，**参考方向不代表实际方向**，仅为计算提供基准。

### 2. 关联参考方向与非关联参考方向
- **关联参考方向**：电流由电压的高电位端（“+”）流向低电位端（“-”）。
- **非关联参考方向**：电流由电压的低电位端（“-”）流向高电位端（“+”）。

### 3. 参考方向的表示方法
1.  箭头标注法（电流/电压参考方向）
2.  双下标标注法（如 `U_ab`，表示 `a` 为“+”，`b` 为“-”）
3.  参考极性标注法（“+”“-”直接标注在元件两端）

## 三、电功率和能量
### 1. 功率的基本公式
- 通用公式：`P = UI`（U、I 为同一元件的电压和电流）

### 2. 功率与参考方向的关系
| 参考方向类型 | 功率符号与物理意义 |
| :--- | :--- |
| 关联参考方向 | `P > 0`：元件**吸收功率**；`P < 0`：元件**发出功率** |
| 非关联参考方向 | `P > 0`：元件**发出功率**；`P < 0`：元件**吸收功率** |

### 3. 无源元件的功率特性
- 电阻：功率恒为吸收（消耗电能）
- 电容、电感：不消耗有功功率，仅与电源进行能量交换

---

## 四、基本电路元件（VCR关系）
电路元件的核心约束为 **VCR（电压电流约束关系）**：

1.  **理想电阻元件（R）**
    - VCR：`U = IR`（欧姆定律）
    - 核心特性：消耗电能，功率恒为吸收。

2.  **理想电容元件（C）**
    - VCR：`i = C·du/dt`
    - 核心特性：储存电场能量，电场能量公式：`W = 1/2·CU²`

3.  **理想电感元件（L）**
    - VCR：`u = L·di/dt`
    - 核心特性：储存磁场能量，磁场能量公式：`W = 1/2·LI²`

4.  **理想电压源**
    - 特性：电压恒定，内阻为 0，电流由外接电路决定。
    - 作用：提供恒定电压。

5.  **理想电流源**
    - 特性：电流恒定，内阻无穷大，电压由外接电路决定。
    - 作用：提供恒定电流。

6.  **受控电源**
    输出量受输入量控制，分为4种类型：

| 受控源类型 | 输入/输出特性 | 控制关系 |
| :--- | :--- | :--- |
| VCVS（电压控制电压源） | 输入开路（`i_c=0`），输出电压受控 | `U_s = μ·U_c` |
| CCVS（电流控制电压源） | 输入短路（`u_c=0`），输出电压受控 | `U_s = r·i_c` |
| VCCS（电压控制电流源） | 输入开路（`i_c=0`），输出电流受控 | `i_s = g·U_c` |
| CCCS（电流控制电流源） | 输入短路（`u_c=0`），输出电流受控 | `i_s = β·i_c` |

## 五、基本电路定律（KCL和KVL）
### 1. 基尔霍夫电流定律（KCL）
- 适用范围：集总参数电路，任意时刻、任意节点（含广义节点）。
- 核心内容：**流入节点的电流之和 = 流出节点的电流之和**（`Σi_入 = Σi_出`）。
- 符号规定：流入节点的电流标“-”，流出节点的电流标“+”，代数和恒为 0。
- 拓展：KCL 不仅适用于节点，也适用于任意闭合曲面（广义节点）。

### 2. 基尔霍夫电压定律（KVL）
- 适用范围：集总参数电路，任意闭合回路。
- 核心内容：**沿任意闭合回路绕行一周，所有元件上的电压代数和为 0**（`Σu = 0`）。
- 符号规定：电位升标“+”，电位降标“-”，沿绕行方向的电压代数和恒为 0。

## 六、个人学习要点与易错点
- 易错点：参考方向与实际方向的混淆，功率符号的判断。
- 关键理解：KCL、KVL 是电路的“守恒定律”，与元件的性质无关，仅由电路的拓扑结构决定。
- 应用：后续电路分析（如节点电压法、回路电流法）的基础。
